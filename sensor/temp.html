준비와 연결

준비물 (한 조)

  • 마이크로비트 1개와 전원(USB 케이블이나 건전지 팩)
  • 방수 온도 센서(DS18B20) 1~2개: 선이 빨강·검정·노랑(또는 흰색) 세 가닥이에요
  • 4.7 kΩ 저항: 센서마다 1개. 센서가 작은 연결 기판에 꽂혀 있으면 보통 저항이 이미 들어 있어요
  • 악어 집게 전선이나 점퍼선

연결

  1. 센서 빨간 선 → 마이크로비트 3V
  2. 센서 검은 선 → 마이크로비트 GND
  3. 센서 노란 선(데이터) → 마이크로비트 1번. 노란 선과 3V 사이에 4.7 kΩ 저항을 이어요.
  4. 두 번째 센서는 같은 방법으로 노란 선을 2번에 이어요. 3V와 GND는 함께 써요.
  5. 마이크로비트를 켜면 마름모가 보여요. A 버튼을 누르면 센서 1 온도가 LED에 지나가서, 태블릿 없이도 센서 연결을 먼저 확인할 수 있어요.

마이크로비트 프로그램 넣기 (선생님이 한 번만)

  1. makecode.microbit.org에서 새 프로젝트를 만들어요.
  2. 확장에서 bluetooth를 추가해요. 라디오를 빼겠냐고 물으면 빼고 추가해요.
  3. 다시 확장의 검색 칸에 github.com/bsiever/microbit-dstemp를 붙여 넣고, 나온 dstemp를 추가해요.
  4. 오른쪽 위 톱니 → 프로젝트 설정에서 No Pairing Required(짝 맺기 없이 누구나 연결)를 켜고 저장해요.
  5. 위쪽 JavaScript 탭에서 원래 코드를 지우고 아래 코드를 붙여 넣은 뒤 다운로드해요. 나온 hex 파일 하나를 모든 조의 마이크로비트에 넣으면 돼요.

마이크로비트 코드

// 마이크로비트 온도 기록기 — 방수 온도 센서(DS18B20) 값을 블루투스(UART)로 보냄
// 확장: bluetooth, dstemp (github:bsiever/microbit-dstemp)
// 연결: 센서 빨강 → 3V, 검정 → GND, 노랑(또는 흰색) → P1. 두 번째 센서는 P2
//       선만 있는 센서는 노랑(데이터)과 3V 사이에 4.7 kΩ 저항을 하나씩 이음
// 한 줄에 보내는 값: T,시간(ms),센서1 온도×100,센서2 온도×100 (읽지 못하면 x)
let connected = false
let t1 = 0
let t2 = 0
function code(t: number): string {
    if (t > -300) {
        return "" + Math.round(t * 100)
    }
    return "x"
}
bluetooth.startUartService()
basic.showIcon(IconNames.Diamond)
bluetooth.onBluetoothConnected(function () {
    connected = true
    basic.showIcon(IconNames.Yes)
})
bluetooth.onBluetoothDisconnected(function () {
    connected = false
    basic.showIcon(IconNames.Diamond)
})
input.onButtonPressed(Button.A, function () {
    basic.showNumber(Math.round(t1 * 10) / 10)
})
basic.forever(function () {
    t1 = dstemp.celsius(DigitalPin.P1)
    t2 = dstemp.celsius(DigitalPin.P2)
    if (connected) {
        bluetooth.uartWriteLine("T," + input.runningTime() + "," + code(t1) + "," + code(t2))
    }
    basic.pause(100)
})

보정은 필요할 때만

이 센서는 공장에서 맞춰져 나와 오차가 약 ±0.5 °C예요. 온도 변화를 보는 실험은 보정 없이 써도 돼요. 두 센서를 비교하는 실험이면 같은 물에 함께 담그고 센서 2를 센서 1에 맞추기를 눌러요. 정확한 온도가 필요하면 실험실 온도계와 같은 물에 담가 그 값으로 맞춰요.

잘 안 될 때

  • 온도 대신 ‘읽지 못해요’가 떠요: 노란 선이 1번에 물렸는지, 4.7 kΩ 저항이 노란 선과 3V 사이에 있는지 확인해요. A 버튼을 눌러 LED에 온도가 나오는지도 봐요.
  • 목록에 마이크로비트가 없어요: 프로그램을 넣었는지, 다른 태블릿에 이미 연결돼 있지 않은지 확인해요. 안드로이드 태블릿에서는 위치(GPS)도 켜야 목록이 보이는 기기가 있어요.
  • 연결하자마자 끊겨요: 프로젝트 설정의 No Pairing Required를 켜고 다시 다운로드해요.
  • 아이패드·아이폰: 브라우저가 블루투스 연결을 지원하지 않아요. 안드로이드 태블릿, 크롬북, 윈도 노트북의 크롬에서 열어요.
