준비와 연결

준비물 (한 조)

  • 마이크로비트 1개와 전원(USB 케이블이나 건전지 팩)
  • 악어 집게 전선 3개 (빨강, 검정, 노랑)
  • 10 kΩ 저항 1개: 집게가 거꾸로 물려도 마이크로비트를 보호해요
  • 멀티미터 1대: 처음 한 번 보정할 때 써요
  • (전류를 잴 때) 100 Ω 저항 1개

연결

  1. 구리판(+) → 빨간 전선 → 10 kΩ 저항 → 노란 전선 → 마이크로비트 1번 단자
  2. 마그네슘판(−) → 검은 전선 → 마이크로비트 GND 단자
  3. 마이크로비트를 켜면 마름모가 보여요. 위의 마이크로비트 연결을 누르고 목록에서 BBC micro:bit [다섯 글자]를 골라요. 연결되면 체크 표시로 바뀌어요.

조마다 마이크로비트의 다섯 글자 이름을 스티커로 붙여 두면, 목록에서 자기 조 것을 바로 고를 수 있어요.

마이크로비트 프로그램 넣기 (선생님이 한 번만)

  1. makecode.microbit.org에서 새 프로젝트를 만들어요.
  2. 확장에서 bluetooth를 추가해요. 라디오를 빼겠냐고 물으면 빼고 추가해요.
  3. 오른쪽 위 톱니 → 프로젝트 설정에서 No Pairing Required(짝 맺기 없이 누구나 연결)를 켜고 저장해요. 이걸 켜야 태블릿에서 따로 짝을 맺지 않고 바로 연결돼요.
  4. 위쪽 JavaScript 탭에서 원래 코드를 지우고 아래 코드를 붙여 넣어요. 블록 탭으로 돌아가면 블록으로도 보여요.
  5. 다운로드해서 나온 hex 파일 하나를 모든 조의 마이크로비트에 똑같이 넣으면 돼요.

마이크로비트 코드

// 마이크로비트 전압 기록기 — 셀 전압을 블루투스(UART)로 보냄
// 연결: 구리판(+) → 10 kΩ 저항 → P1,  마그네슘판(−) → GND
// 한 줄에 보내는 값: 시간(ms),P1 값 32번의 합,P2 값 32번의 합,32
let connected = false
bluetooth.startUartService()
basic.showIcon(IconNames.Diamond)
bluetooth.onBluetoothConnected(function () {
    connected = true
    basic.showIcon(IconNames.Yes)
})
bluetooth.onBluetoothDisconnected(function () {
    connected = false
    basic.showIcon(IconNames.Diamond)
})
basic.forever(function () {
    let s1 = 0
    let s2 = 0
    for (let index = 0; index <= 31; index++) {
        s1 += pins.analogReadPin(AnalogPin.P1)
        s2 += pins.analogReadPin(AnalogPin.P2)
    }
    if (connected) {
        bluetooth.uartWriteLine("" + input.runningTime() + "," + s1 + "," + s2 + ",32")
    }
    basic.pause(100)
})

보정 (수업마다 한 번)

  1. 마이크로비트를 이은 채로 멀티미터도 같은 두 판에 물려요. 빨간 리드는 구리판, 검은 리드는 마그네슘판이에요.
  2. 두 값이 안정되면 멀티미터 값을 보정 칸에 적고 이 값으로 맞추기를 눌러요.
  3. 마이크로비트 전원을 바꾸면(USB ↔ 건전지) 다시 보정해요. 마이크로비트는 전원 전압을 기준으로 재기 때문이에요.

전류 재기 (선택)

두 판 사이에 100 Ω 저항을 함께 물리고, 두 판 사이에 문 저항에서 100 Ω을 골라요. 전류는 전압 ÷ 저항으로 계산해요. 이 값은 LED처럼 부하가 있을 때 흐르는 전류여서, 멀티미터만 이어 재는 단락 전류보다 작아요.

잘 안 될 때

  • 목록에 마이크로비트가 없어요: 프로그램을 넣었는지, 다른 태블릿에 이미 연결돼 있지 않은지 확인해요. 안드로이드 태블릿에서는 위치(GPS)도 켜야 목록이 보이는 기기가 있어요.
  • 연결하자마자 끊겨요: 프로젝트 설정의 No Pairing Required를 켜고 다시 다운로드해요. 예전에 태블릿 블루투스 설정에서 짝을 맺었다면 그 기기를 지워요.
  • 값이 0 V 근처예요: 집게가 떨어졌거나 판이 거꾸로 물렸어요. 구리판이 1번 쪽, 마그네슘판이 GND 쪽이에요.
  • 아이패드·아이폰: 브라우저가 블루투스 연결을 지원하지 않아요. 안드로이드 태블릿, 크롬북, 윈도 노트북의 크롬에서 열어요.
