마이크로비트 처음 시작하기

2026. 10. 3. · KJE

1. 마이크로비트란?

마이크로비트(micro:bit)는 약 4 cm × 5 cm 크기의 작은 컴퓨터예요. 블록을 끌어다 놓는 방식으로 누구나 쉽게 프로그램을 만들 수 있어요. 영국 BBC가 학생 코딩 교육용으로 만들었고, 지금은 비영리 단체인 마이크로비트 교육재단이 관리해요.

지금 판매되는 모델은 V2(버전 2)예요. 뒷면에 스피커와 마이크가 있고, 앞면 금색 로고를 터치 버튼으로 쓸 수 있으면 V2예요. 이 자료는 V2를 기준으로 설명해요.

마이크로비트로 할 수 있는 일은 다음과 같아요.

  • LED 화면에 글자, 숫자, 그림 띄우기
  • 버튼 누르기, 흔들기, 기울이기 감지하기
  • 온도, 빛의 세기, 소리 크기 측정하기
  • 소리와 멜로디 재생하기
  • 다른 마이크로비트와 무선으로 메시지 주고받기
  • 모터, LED, 센서 같은 외부 부품 연결해 제어하기

2. 각 부분 살펴보기

마이크로비트를 앞뒤로 뒤집어 보며 아래 부품을 하나씩 찾아보세요. 센서 대부분은 뒷면에 있어요.

부품 위치 하는 일
LED 화면 앞면 가운데 빨간 LED 25개(5 × 5)로 글자와 그림을 표시해요. 주변 빛의 세기도 감지해요.
버튼 A, B 앞면 왼쪽, 오른쪽 누르면 정해 둔 동작을 실행해요. 두 개를 함께 누를 수도 있어요.
터치 로고 앞면 위쪽 금색 로고 손가락으로 만지면 버튼처럼 작동해요.
핀(금속 띠) 앞면 아래쪽 가장자리 큰 구멍 0, 1, 2번 핀과 3V, GND로 외부 부품을 연결해요.
마이크로 USB 포트 뒷면 위쪽 컴퓨터와 연결해 프로그램을 받고 전원을 얻어요.
배터리 연결부 뒷면 위쪽 AAA 건전지 2개짜리 배터리 팩을 꽂아요.
리셋 버튼 뒷면 위쪽 누르면 프로그램을 처음부터 다시 실행해요. 길게 누르면 전원이 꺼져요.
스피커 뒷면 가운데 소리와 멜로디를 내요.
마이크 뒷면 주변 소리의 크기를 감지해요. 켜지면 앞면 로고 옆 작은 LED가 켜져요.
가속도·나침반 센서 뒷면 흔들기, 기울기, 방향(동서남북)을 감지해요.
프로세서(두뇌) 뒷면 프로그램을 실행하고 온도를 재며, 무선 통신을 담당해요.

온도는 프로세서 칩의 온도를 재는 것이라 실제 기온보다 조금 높게 나올 수 있어요.

3. 준비물과 연결

마이크로비트, USB 케이블, 인터넷이 되는 컴퓨터만 있으면 바로 시작할 수 있어요.

준비물 설명
마이크로비트 V2 이 자료의 기준 모델이에요.
마이크로 USB 케이블 데이터 전송이 되는 케이블이어야 해요. 충전 전용 케이블은 인식되지 않아요.
컴퓨터 윈도우, 맥, 크롬북 모두 가능해요. 크롬이나 엣지 브라우저를 권장해요.
배터리 팩(선택) AAA 건전지 2개용이에요. 컴퓨터 없이 들고 다니며 실행할 때 써요.

연결 순서는 다음과 같아요.

  1. USB 케이블의 작은 쪽을 마이크로비트 뒷면 포트에, 큰 쪽을 컴퓨터에 꽂아요.
  2. 뒷면 USB 옆 작은 LED가 켜지는지 확인해요.
  3. 컴퓨터의 파일 탐색기(맥은 Finder)에 MICROBIT라는 드라이브가 보이면 연결 성공이에요.

마이크로비트는 받은 프로그램을 기억해요. 전원을 껐다 켜도 마지막 프로그램이 다시 실행돼요.

뒷면 부품이 드러나 있으니 금속 책상이나 물기 있는 곳에 두지 마세요. 합선으로 고장 날 수 있어요.

4. MakeCode 편집기 둘러보기

마이크로비트 프로그램은 웹 브라우저에서 MakeCode 편집기로 만들어요. 설치나 회원가입 없이 바로 쓸 수 있고, 만든 프로젝트는 브라우저에 자동 저장돼요.

처음 접속했다면 이렇게 시작하세요.

  1. 오른쪽 위 톱니바퀴 → Language → 한국어를 골라 메뉴를 한국어로 바꿔요.
  2. 새 프로젝트를 누르고 이름을 입력한 뒤 만들기를 눌러요.
화면 영역 위치 쓰임
시뮬레이터 왼쪽 가상 마이크로비트예요. 실제 기기 없이 코드 결과를 미리 볼 수 있어요.
블록 메뉴 가운데 기본, 입력, 음악, LED, 무선통신, 반복, 논리, 변수, 계산 등 종류별로 블록이 모여 있어요.
작업 공간 오른쪽 넓은 곳 블록을 끌어와 퍼즐처럼 조립하는 곳이에요.
언어 전환 탭 위쪽 가운데 블록, JavaScript, Python 중 원하는 방식으로 볼 수 있어요.
다운로드 버튼 왼쪽 아래 완성한 프로그램을 마이크로비트로 보내요.

새 프로젝트에는 시작하면 실행(on start)과 무한반복 실행(forever) 블록이 기본으로 놓여 있어요. 앞의 것은 전원이 켜질 때 한 번, 뒤의 것은 계속 반복해서 실행돼요.

필요 없는 블록은 블록 메뉴 쪽으로 끌어다 놓으면 지워져요. 블록 이름은 편집기 버전에 따라 조금 다를 수 있어서, 이 자료에는 영어 원래 이름을 괄호로 함께 적었어요.

5. 첫 번째 프로그램 만들기

첫 프로그램은 두근거리는 하트와 흐르는 글자예요. 블록 4개면 완성되고, 시뮬레이터로 바로 확인할 수 있어요.

예제 1. 두근거리는 하트

  1. 블록 메뉴에서 기본을 눌러요.
  2. 아이콘 출력(show icon) 블록을 끌어 무한반복 실행 안에 넣어요. 기본 모양이 큰 하트예요.
  3. 같은 블록을 하나 더 끌어와 첫 블록 바로 아래에 붙여요.
  4. 두 번째 블록의 하트 옆 화살표를 눌러 작은 하트로 바꿔요.
  5. 시뮬레이터에서 하트가 커졌다 작아졌다 하는지 확인해요.
무한반복 실행
    아이콘 출력 (큰 하트)
    아이콘 출력 (작은 하트)

예제 2. 이름 흐르게 하기

  1. 기본 → 문자열 출력(show string) 블록을 시작하면 실행 안에 넣어요.
  2. "Hello!" 자리를 눌러 내 이름을 영어로 입력해요. 예: KIM
  3. 시뮬레이터에서 글자가 오른쪽에서 왼쪽으로 지나가는지 확인해요.

LED 화면은 5 × 5 칸이라 한글은 표시할 수 없어요. 영어 알파벳, 숫자, 일부 기호만 쓸 수 있어요.

직접 그려 보기

기본 메뉴에서 5 × 5 칸이 그려진 블록(show leds)을 쓰면 나만의 그림을 만들 수 있어요. 칸을 클릭할 때마다 LED가 켜지고 꺼져요. 웃는 얼굴, 화살표, 이니셜을 그려 보세요.

6. 마이크로비트로 옮기기

크롬이나 엣지에서는 직접 연결 방식이 가장 편해요. 사파리 등 다른 브라우저에서는 파일 끌어놓기 방식을 쓰세요.

방법 A. 직접 연결(크롬·엣지)

  1. 마이크로비트를 USB로 연결한 상태에서 다운로드 버튼을 눌러요.
  2. 처음 한 번은 기기 연결 안내 창이 떠요. 안내를 따라가다 목록에 나온 BBC micro:bit를 고르고 연결을 눌러요.
  3. 뒷면 LED가 깜빡이다 멈추면 전송 완료예요. 프로그램이 바로 실행돼요.

한 번 연결해 두면 그다음부터는 다운로드 버튼만 누르면 바로 전송돼요.

방법 B. 파일 끌어놓기

  1. 다운로드 버튼을 누르면 microbit-프로젝트이름.hex 파일이 다운로드 폴더에 저장돼요.
  2. 이 파일을 MICROBIT 드라이브로 끌어다 놓아요.
  3. 뒷면 LED가 깜빡이다 멈추면 완료예요.

전송이 끝나면 MICROBIT 드라이브가 잠깐 사라졌다 다시 나타나요. 드라이브 안에 hex 파일이 보이지 않아도 정상이에요. 맥에서 "디스크를 올바르게 추출하지 않았습니다" 경고가 떠도 무시해도 괜찮아요.

7. 버튼과 센서 써 보기

입력 블록을 쓰면 마이크로비트가 사람의 동작과 주변 환경에 반응해요. 아래 세 예제는 각각 블록 2~3개로 만들 수 있어요.

예제 3. 버튼으로 표정 바꾸기

  1. 입력 → A 누르면 실행(on button A pressed) 블록을 작업 공간에 놓아요.
  2. 그 안에 아이콘 출력 블록을 넣고 웃는 얼굴을 골라요.
  3. 같은 묶음을 하나 더 만들고, A를 B로, 웃는 얼굴을 슬픈 얼굴로 바꿔요.
A 누르면 실행
    아이콘 출력 (웃는 얼굴)
B 누르면 실행
    아이콘 출력 (슬픈 얼굴)

예제 4. 흔들면 굴러가는 주사위

  1. 입력 → 흔들림 감지하면 실행(on shake) 블록을 놓아요.
  2. 그 안에 기본 → 수 출력(show number) 블록을 넣어요.
  3. 숫자 자리에 계산 → 랜덤(pick random) 블록을 끼우고 범위를 1부터 6까지로 바꿔요.
흔들림 감지하면 실행
    수 출력 (랜덤 1 부터 6 까지)

시뮬레이터에서는 SHAKE 버튼을 눌러 흔들기를 흉내 낼 수 있어요.

예제 5. 버튼 온도계

  1. A 누르면 실행 블록 안에 수 출력 블록을 넣어요.
  2. 숫자 자리에 입력 → 온도(temperature) 블록을 끼워요.
  3. A 버튼을 누를 때마다 현재 온도(°C)가 표시돼요. 손으로 칩을 잡고 있으면 숫자가 올라가는 것도 볼 수 있어요.

측정할 수 있는 값 정리

아래 블록은 모두 입력 메뉴에 있고, 수 출력 블록 안에 끼워 값을 확인해요.

측정 대상 블록(영어 이름) 값의 범위
온도 temperature 섭씨(°C) 정수
빛의 세기 light level 0(어두움) ~ 255(밝음)
소리 크기 sound level 0(조용함) ~ 255(시끄러움)
방향 compass heading 0 ~ 359°(0 = 북쪽)

값을 일정 시간마다 기록하면 온도 변화나 빛 세기 비교 같은 간단한 측정 실험이 돼요.

8. 자주 겪는 문제와 해결

문제 대부분은 케이블, 연결 방식, 전원에서 생겨요. 코드를 의심하기 전에 아래 표부터 확인하세요.

증상 원인 해결
MICROBIT 드라이브가 안 보여요 충전 전용 케이블이거나 연결이 헐거워요 다른 케이블이나 다른 USB 포트에 꽂아 보세요.
직접 연결 목록에 기기가 없어요 다른 브라우저 탭이 이미 연결을 쓰고 있어요 MakeCode 탭을 하나만 남기고 케이블을 다시 꽂으세요.
다운로드했는데 그대로예요 hex 파일이 MICROBIT 드라이브로 옮겨지지 않았어요 다운로드 폴더의 hex 파일을 MICROBIT 드라이브로 다시 끌어다 놓으세요.
TILT TO FILL SCREEN 글자가 흘러가요 나침반 블록을 처음 쓰면 보정이 필요해요 마이크로비트를 이리저리 기울여 LED 25개를 모두 켜면 끝나요.
슬픈 얼굴과 숫자가 번갈아 떠요 프로그램 실행 중 오류가 났어요 코드를 확인하고 다시 다운로드하세요. 숫자는 오류 종류를 뜻해요.
화면이 꺼지고 반응이 없어요 리셋 버튼을 길게 눌러 전원이 꺼졌거나 건전지가 닳았어요 리셋 버튼을 한 번 누르거나 건전지를 바꾸세요.
한글이 표시되지 않아요 LED 화면은 한글을 지원하지 않아요 영어나 숫자로 바꾸거나, 5 × 5 그림 블록으로 직접 그려요.

9. 다음 단계

기본 예제를 마쳤다면 아래 활동으로 넘어가 보세요.

  • 무선 통신: 무선통신 메뉴에서 그룹 번호를 같게 맞추면 마이크로비트끼리 숫자와 글자를 주고받을 수 있어요.
  • 데이터 기록: V2는 측정값을 내부에 저장했다가 컴퓨터에서 표와 그래프로 볼 수 있어요. 확장 메뉴에서 datalogger를 추가하세요.
  • 외부 부품 연결: 악어 클립으로 0, 1, 2번 핀과 GND에 LED, 스피커, 센서를 연결해 보세요.
  • 텍스트 코딩: 블록이 익숙해지면 상단 탭에서 JavaScript나 Python으로 바꿔 같은 코드를 글로 확인해 보세요.
