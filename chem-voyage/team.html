교사용 도구

수업용 파일 만들기

설정이 박힌 실험실 파일을 만든다. 학교 사이트에 올리거나 학생 기기에 넣어 쓴다.

모둠 연결: 학교 서버(Supabase) 학교 사이트에 올려 쓸 때만

claude.ai 링크로 쓰면 필요 없다. 학교 사이트에 올린 파일로 조별 플레이를 하려면 무료 Supabase 프로젝트를 만들고 아래처럼 준비한다.

1) Authentication → Sign In / Providers에서 Anonymous sign-ins를 켠다. 2) SQL Editor에서 아래를 한 번 실행한다.

create table voyage_groups (id text primary key, state jsonb, updated_at timestamptz default now());
create table voyage_members (room text, uid uuid default auth.uid(), primary key (room, uid));
alter table voyage_groups enable row level security;
alter table voyage_members enable row level security;
create policy "join" on voyage_members for insert to authenticated with check (uid = auth.uid());
create policy "mine" on voyage_members for select to authenticated using (uid = auth.uid());
create policy "read" on voyage_groups for select to authenticated using (exists (select 1 from voyage_members m where m.room = id and m.uid = auth.uid()));
create policy "add" on voyage_groups for insert to authenticated with check (exists (select 1 from voyage_members m where m.room = id and m.uid = auth.uid()));
create policy "edit" on voyage_groups for update to authenticated using (exists (select 1 from voyage_members m where m.room = id and m.uid = auth.uid()));
create policy "live read" on realtime.messages for select to authenticated using (exists (select 1 from voyage_members m where m.room = (select realtime.topic()) and m.uid = auth.uid()));
create policy "live send" on realtime.messages for insert to authenticated with check (exists (select 1 from voyage_members m where m.room = (select realtime.topic()) and m.uid = auth.uid()));

3) Realtime → Settings에서 Allow public access를 끈다. 그러면 실시간 연결도 그 모둠 방에 들어온 기기만 쓸 수 있다.

각 모둠의 기록은 그 모둠 방에 들어온 기기만 읽고 쓸 수 있다. 방 이름은 이 수업 파일에만 들어 있는 비밀값과 학년·반·회차·조로 만들어져서 파일 밖에서는 알 수 없다. 다만 수업 파일을 가진 사람은 누구나 방을 고를 수 있으니, 파일은 수업 대상에게만 나눠 준다. 오가는 것은 이름표용 이름, 위치, 모둠 진행뿐이다.

학생 명단 선택. 넣으면 명단 학생만 개인 코드로 들어온다

학년, 반, 번호, 이름을 한 줄에 한 명씩. 엑셀에서 네 칸을 복사해 붙여도 된다. 다섯째 칸에 6자리 코드가 있으면 그대로 쓴다.

기존 수업 파일 업데이트

쓰던 수업 파일을 불러오면 수업 번호, 교사 비밀번호, 명단, 설정은 그대로 두고 실험실만 최신으로 바꾼 파일을 만든다. 같은 사이트에서 열면 학생 기록이 이어진다.

이 기기 기록 관리

이 기기에서 이 수업 파일로 한 학생들의 기록을 한 번에 받거나 정리한다. 수업용 파일을 만들 때 정한 교사 비밀번호가 필요하다.

로그인 없이 쓰는 프로그램이다. 입력한 정보와 실험 기록은 이 기기의 브라우저에만 저장되며, 따로 서버로 보내지 않는다. 결과는 제출 파일로 내려받아 선생님께 낸다.
